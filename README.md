# Tip Calculator - Collaborative Project

## 📋 Project Overview

A simple, user-friendly tip calculator built with HTML, CSS, and JavaScript. This project demonstrates fundamental web development concepts including user input handling, mathematical calculations, and dynamic DOM manipulation.

## 🎯 What You'll Build

A practical tip calculator that allows users to:

- Enter a bill amount
- Specify a custom tip percentage
- Calculate the total with one click
- View the formatted final total

## ✨ Features

- **Bill Amount Input**: Clean numeric input field for bill amount
- **Custom Tip Percentage**: Flexible tip percentage input
- **One-Click Calculation**: Single button to process and display results
- **Formatted Output**: Properly formatted currency display

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Basic understanding of HTML, CSS, and JavaScript
